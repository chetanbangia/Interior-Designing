# Asteria Interiors Website

Complete responsive informational website for an interior-design organization.

## Pages
Home, About, Services, Our Work, Contact.

## Features
- Responsive design
- Mobile navigation
- Dynamic project portfolio
- Category filters
- Project detail modal
- Dynamic services/process/team sections
- Contact enquiry form
- Enquiries stored in browser localStorage
- No backend required
- Works by opening index.html directly

## Customize
Edit `assets/js/data.js` to change projects, services, team and content.
Replace the placeholder SVG images in `assets/images/` with your own licensed project photographs.
Replace the example email/phone/address before publishing.
